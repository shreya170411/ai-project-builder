Target:

Goal:

Generate 500 registrations within 7 days.

phone

graduation_year

target_role

referral_code

referred_by

referral_count

reward_unlocked

created_at

Rules:

- Email must be unique.

- Generate a unique referral code for every registration.

- Store referred_by when a registration comes through another user's referral link.

- Increment referral_count only after a successful referred registration.

- Unlock reward at 2 successful referrals.

- Do not count the user's own registration.

- Prevent duplicate referrals from the same email.
